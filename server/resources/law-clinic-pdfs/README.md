Place law clinic resource PDFs and text documents in this folder.

The AI assistant reads relevant files from here before answering sensitive,
procedural, policy, ethics, confidentiality, intake, or client-handling
questions.

Supported file types:
- PDF
- TXT, Markdown, CSV, JSON, HTML, XML, RTF

These files are intentionally ignored by git. Keep real clinic documents on the
server only. The assistant reads this folder on each request, so newly added
resources are available without a code change.
